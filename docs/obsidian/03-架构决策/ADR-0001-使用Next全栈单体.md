# ADR-0001：使用 Next.js 全栈单体

## 背景

学习目标是让已有前端经验的工程师补齐后端、AI 和 SaaS 工程能力。如果一开始拆成独立前后端，会增加环境、部署和跨服务调试复杂度。

## 决策

第一阶段采用 Next.js App Router 全栈单体：

- UI、路由和服务端数据获取在 `apps/web`。
- 数据库 schema 和迁移配置在 `packages/db`。
- 复杂业务逻辑逐步沉淀到 service 层，而不是散落在页面组件里。

## 后果

- 优点：学习闭环快，部署简单，适合中小 SaaS 起步。
- 代价：后期如果后台任务、权限、AI 工作流变复杂，可能需要拆独立服务。
