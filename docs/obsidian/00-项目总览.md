# 项目总览

## 项目定位

AI 客服知识库 SaaS 后台，用于训练前端工程师在 AI 时代需要的全栈产品交付能力。

这个项目不是一次性 demo，而是长期陪跑学习系统。代码、笔记、决策和 Codex 协作规范都会保存在仓库里，方便 Mac/Windows 跨设备继续。

## 核心能力

- 登录与团队空间
- 知识库管理
- 文档上传、解析、切分
- embedding 入库
- pgvector 相似度检索
- AI 客服问答与引用来源
- 用户反馈和未解决问题收集
- 后台数据看板
- 权限、用量、审计日志

## 技术栈

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- shadcn/ui 风格组件
- Prisma ORM
- PostgreSQL，RAG 阶段再引入 pgvector
- Redis
- Docker Compose
- OpenAI API

说明：第一阶段先用 Prisma + 标准 PostgreSQL 学习主流 SaaS 数据建模和 migration。pgvector 和向量检索会在 RAG 阶段单独讲，不要求现在掌握。

## 学习原则

- 项目驱动，不做孤立练习题。
- 先解释概念，再进入代码。
- 每次迭代都留下笔记。
- 优先贴近真实业务和主流工程实践。
