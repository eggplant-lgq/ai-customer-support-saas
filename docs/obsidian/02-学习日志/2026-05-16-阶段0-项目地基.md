## 关键概念

- **monorepo**：一个仓库管理多个应用和包，方便共享配置、类型和文档。
- **Docker Compose**：用一个配置文件描述本地依赖服务，例如 PostgreSQL、Redis。
- **Prisma**：常见的 TypeScript ORM，用 schema 描述数据库表和关系，再生成类型安全的数据库客户端。
- **pgvector**：PostgreSQL 的向量扩展，后续用于 RAG 的相似度检索；现阶段只知道它会用于“从知识库里找相关内容”即可。
- **项目记忆层**：把上下文写入仓库文档，让 Codex 换设备后也能恢复状态。
